# 🐾 Latte Paws

Premium dog printables & gifts for pet lovers.

## 🚀 Deploy to Live Website

### 最快方式：Netlify（免費，5分鐘）

1. 去 https://app.netlify.com
2. Login with Google/GitHub
3. Drag & drop `index.html` 檔案入 Netlify
4. ✅ 搞掂！你會得到 `lattepaws.netlify.app`

### 自訂 Domain

1. Netlify Dashboard → Domain Settings
2. Add custom domain → 輸入 `lattepaws.com`
3. Update DNS（Netlify 會俾 nameserver 你）
4. ✅ 你嘅 domain 就 connect 咗

## 💳 Connect Stripe（收錢）

### Step 1: 開 Stripe Account

1. 去 https://dashboard.stripe.com/register
2. 用你個人身份開（唔需要公司）
3. 填香港地址 + 銀行戶口

### Step 2: Get 你的 Stripe Key

1. Stripe Dashboard → API Keys
2. Copy **Publishable Key**（開頭係 `pk_live_`）

### Step 3: Create Payment Link

1. Stripe Dashboard → Products → Add Product
2. Create products for each printable
3. Create a **Payment Link**
4. 將 link 放入 `checkout()` function 入面

### Step 4: 自動 Deliver Digital Products

用 **Stripe Digital Goods**（Search "Digital Goods" in Stripe Dashboard）
→ 有人俾錢就自動 send email 俾 download link
